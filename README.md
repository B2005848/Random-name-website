# Website gọi tên ngẫu nhiên bằng hoạt ảnh đập muỗi
## Các chức năng chính
1. Quản lí danh sách lớp.
2. Chỉnh sửa chế độ bay của muỗi: nhanh / vừa / chậm.
3. Chỉnh sửa tốc độ đập muỗi: nhanh / vừa / chậm.
4. Đập tên không trùng lặp.
5. Dữ liệu lưu localstorage.

## Cách sử dụng
Tải file index.html về và mở bằng trình duyệt bất kì.
